# 静泊 · Cala Serena

桌面全屏等距树脂海湾微缩场景，按桌面浏览器和鼠标操作设计。Vite、React 19、TypeScript、three、React Three Fiber **v9**、drei、@react-three/postprocessing 和 Leva。所有三维几何、材质表面纹理、沙纹和焦散都由代码生成；唯一外部三维照明资源是 drei 的 `Environment preset="city"`，没有模型文件。页面字体有本地字体回退。

## 运行

需要 Node.js 22.12+（或 24）与 pnpm 11.25.0。

```sh
pnpm install --frozen-lockfile
pnpm dev
```

本地地址：http://127.0.0.1:5194/

```sh
pnpm build
pnpm preview
```

也可使用 npm install / npm run dev；随项目提供的 pnpm-lock.yaml 锁定了验证过的依赖版本。

## 交互

- 移动鼠标划过水面：速度决定连续涟漪的扰动强度。
- 点击水面：加入更大的径向脉冲，波纹在有限差分高度场中传播、叠加并衰减。
- 左键拖拽：360° 环绕旋转。右键拖拽：平移。滚轮：缩放。
- 拖拽旋转时也持续注入鼠标涟漪，并把相机旋转 / 平移速度转换成 GPU 水面的横向压力；松手后水体保留独立的衰减惯性。按下与松开移动小于 5px 才额外触发点击径向脉冲。
- 空格：暂停 / 继续。R：重置水面、弹簧惯性与初始等距视角。
- “调校”：打开完整 Leva 参数面板。
- 沉浸按钮：隐藏文案。Escape：关闭面板 / 退出沉浸。
- 页面在后台时停止绘制。减少动态效果偏好会降低整体倾斜幅度。

## 结构与技术

`src/Experience.tsx` 组装相机、树脂块、海岸、村庄、码头、船、植被、灯光及后期；`src/scene/` 按职责拆分。

`useWaterSimulation()` 用两个 HalfFloat RenderTarget 保存 R=高度、G=速度、B=拉普拉斯。固定 1/120 秒步长，显式有限差分求解，传播系数限定在稳定区间；边界与陆地处吸收波动。风是连续随机小力，直接作用于速度场。每帧最多六步，暂停与重置独立处理，不在 CPU 上修改水面顶点。

鼠标脉冲使用面积平衡的中心波峰 / 外圈波谷，避免重复划动持续抬高平均水位；饱和单元会释放积累速度，微弱高度回归使海湾恢复静水。不同 FBO 分辨率按网格间距校准传播系数，降档时不会突然改变波速。动态水面在圆角边缘平滑归零，与树脂侧壁保持连接。

`usePointerWaterInteraction()` 把世界射线命中点变成局部 UV；鼠标脉冲有事件节流和限长队列。

`useWaterRefraction()` 共享一次无 tone mapping 的场景捕获供 MeshTransmissionMaterial 和顶部水面使用，捕获时排除两者，防止纹理反馈。树脂采用透射、IOR、厚度、吸收与双面渲染；顶部高细分平面独立位移，使用 Fresnel、来自 Environment 的 PMREM 反射、场景折射、海岸距离与浪峰相关泡沫。

`Caustics` 在标准材质中注入动态程序化细胞焦散；高度场的局部法线梯度和太阳方向改变投影。它是受水面驱动的视觉焦散近似，不是光子追踪求解。

256² 静态深度贴图由真实沙床高度和同一组礁石实例的旋转椭球近似生成，驱动浅 / 深水混色、光吸收与浅水泡沫。它在初始化时计算，不参与 CPU 每帧顶点更新。焦散通过景观块的逆矩阵采样局部水域，整体倾斜和抬升后仍能保持正确的水下范围。

`useDioramaMotion()` 包含弹簧速度与阻尼，以及水体倾斜的额外低通响应。`useBoatFloat()` 从 GPU 上每秒 15 次异步读取一个局部高度 / 坡度样本，再通过独立的船体弹簧做浮动和俯仰。仅系泊绳索的小网格在船体明显移动时更新。

增强互动版本的默认波浪高度从 0.52 增至 2.4，鼠标扰动从 0.65 增至 2.6，整体晃动从 0.022 增至 0.1，并延长水面衰减、增强船体浮动。波浪仍使用 GPU 求解；移除了静态树脂顶盖，让增强后的波峰和波谷都能呈现。厚块倾斜时补偿底部高度，台面主光投影随之更新；柔和接触阴影缓存一次。

页面失去焦点时改为按需绘制，鼠标重新进入场景或页面获得焦点后恢复动画，避免多个海湾标签页同时持续占用 GPU。后台按需帧不计入性能降档判定。

海岸包含连续岩体、底面、侧面与后侧礁岩；石屋补有嵌入地形的基座、门前铺石、屋檐梁、局部露石墙面与背窗。码头增加连接桩基与横梁的斜撑；盘绳使用平面螺旋管体，花盆使用带盆口和内壁的旋转几何体。渔船甲板朝向已修正。岩石采用平滑连续噪声，叶片加入收细形状与分枝，表面纹理增加木节、灰泥斑驳、陶瓦色差和沙纹。

精细 / 均衡档使用 PCSS 柔和阴影，轻量档关闭。摄影后期保持克制。相机复位会重新创建 OrbitControls，清除残余旋转阻尼；暂停时复位也清空块体、船体和水体的惯性。

`CameraRig` 使用 drei `OrbitControls` 的阻尼旋转、平移和正交缩放，限制仰俯角以避免穿过桌面；复位回到等距构图。共享折射捕获在相机更新之后执行，保持旋转时水下折射与视角一致。

屋顶陶瓦、码头木板、石砌块、礁石、砂砾和植被使用 InstancedMesh；几何和材质共享，随机数固定种子。岩石使用连续位移和光滑法线，不使用低多边形平面着色。

## 自适应质量

| 项目 | 精细 | 均衡 | 轻量 |
| --- | --- | --- | --- |
| 水面 FBO | 192² | 128² | 64² |
| 水面细分 | 160² | 112² | 64² |
| 折射捕获宽度 | 768 | 512 | 320 |
| 透射采样数 | 4 | 2 | 1 |
| 阴影贴图 | 2048² | 1024² | 512² |
| 植被比例 | 100% | 70% | 45% |
| 焦散 / 泡沫细节 | 高 | 中 | 低 |
| DPR 上限 | 1.5 | 1.1 | 0.85 |
| 后期 | SSAO / DOF / Bloom / Vignette | 降分辨率与采样 | 关闭 |

桌面默认精细档，低核心数桌面从均衡档启动；预热后连续两个 3 秒窗口低于 48fps 会逐级降档，避免反复振荡。桌面目标 60fps，实际表现取决于 GPU、屏幕与浏览器。`main` 元素的 `data-fps` / `data-quality` / `data-calls` 供开发检查。质量策略不再依据触屏或窄屏判断，页面没有手机专用布局。

性能窗口要求页面处于前台并获得焦点；超过 250ms 的停帧会重新预热，避免浏览器暂停或调试造成错误降档。帧率统计使用实际时间间隔。

## 验证

TypeScript 编译与 Vite 生产构建通过。正式构建已在浏览器验证，检查期间没有新的控制台错误。

- 初始等距基础版本，1440 × 960 桌面精细档：RTX 4060 Ti / ANGLE D3D11 的检测窗口约 180fps（本机刷新率上限附近）。此数字不代表所有硬件，也不是增强互动版本的性能保证。
- GPU 初始采样为 `128,128,128,255`，对应零高度 / 零速度；点击和拖动后脉冲队列增加，局部高度随模拟改变。
- Leva IOR 从 1.34 修改到 1.36 后实时生效；Escape 关闭面板并恢复控制按钮焦点。
- 已验证暂停 / 继续、点击水面、沉浸模式和重置入口。
- 增强互动版本已验证旋转后相机坐标改变、拖拽脉冲增加、`data-drag-wave` 松手后衰减，以及滚轮缩放和等距复位；检查期间无新的控制台错误。
- 精修版本已检查背面岩体、房屋基座和水下斜撑，并在正式构建中验证拖拽起浪与暂停复位。GPU 异步船体采样带有版本检查，复位或 FBO 重新初始化后不会接受旧的读回结果。

代码保留 FBO、阴影、DPR、植被、焦散、泡沫和后期的桌面性能自动降级。
