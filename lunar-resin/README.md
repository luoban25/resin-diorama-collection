# 月栖 · Luna

桌面等距月面湖泊微缩场景。本地网页直接打开，无登录流程。沿用 Vite、React、TypeScript、three、React Three Fiber v9、drei、postprocessing 和 Leva。

## 运行

需要 Node.js 22.12+。安装依赖后运行：

```sh
pnpm install --frozen-lockfile
pnpm dev
```

本地预览：http://127.0.0.1:5197/

```sh
pnpm build
pnpm preview
```

## 场景

所有模型、岩体凹坑、表面纹理和焦散由代码生成，没有加载模型文件。环境基础为 drei 的 `Environment preset="city"`。页面字体有本地字体回退。

- `LunarTerrain`：陆地与湖水沿不规则对角线分开，俯视投影约 61% 陆地 / 岩石、39% 湖水。左岸向湖中延伸并逐级下降。224² 网格、多尺度不规则陨石坑、细砂砾、车辙和基岩；湖水直接延伸到展示块外缘，干燥陆地保留完整剖面。
- `lunarSidesGeometry`：320 × 88 侧壁网格，带暖灰、灰褐和蓝灰变化的起伏岩层，薄层接缝、真实凹坑，以及骨骸展示凹槽。
- `FossilSkeleton`：嵌在右侧岩层中的外星人化石骨骸。程序化颅骨、眼窝、下颌、椎骨、肋骨、骨盆和细长四肢。骨骸管线合并为一个网格，其余重复细节实例化。
- `LunarOutpost`：带桌椅与暖光的分面居住舱、检修口、通风口、铆钉与标记；探测车采用正确的框架 / 轴结构，并加入挡泥板、轮毂螺栓、格栅、后视镜、门缝和标记。另有通讯塔、设备箱与电缆。
- `lunarMaterials`：1024² 程序化颜色、法线、粗糙度贴图，以及带细微磨损的金属涂层。所有贴图均在初始化生成，数据贴图和颜色贴图使用各自正确的色彩空间。
- `lunarGeometry`：共享地形高度与湖泊边界。256² 深度 / 湿区贴图在初始化计算，供模拟、水色、岸边泡沫和焦散共同使用。
- `ResinWaterBlock`：贴合不规则湖岸的独立湖水体积与 GPU 位移水面。水面、水体和岩体共享 7.6 宽、0.45 圆角半径的外轮廓，圆弧几何与 shader 遮罩一致；前方透明剖切面与岩层外侧直接对齐，后侧为封闭岩层。清澈蓝色吸收、环境反射、Fresnel、场景折射、细微法线和太阳高光。
- `useWaterSimulation`：双 HalfFloat RenderTarget，R=高度、G=速度、B=拉普拉斯；固定 1/120 秒步长。波纹可传播、叠加、衰减；鼠标速度决定扰动，拖拽相机也向水面注入横向压力。没有 CPU 每帧修改水面顶点。
- `Caustics`：程序化动态焦散，受水面梯度驱动，并用湿区遮罩避免染色到干燥剖面。属于视觉近似。

## 交互

移动鼠标划过湖面起浪，点击产生径向波纹。左键旋转、右键平移、滚轮缩放。R 恢复等距视角与静水，空格暂停 / 继续，Escape 关闭面板。调校按钮打开 Leva。

默认缩放为 0.94，比上一版放大约 15%，主体四周保留留白。装置集中于后侧，不遮挡湖面。页面处于后台时按需绘制；桌面根据性能降低 FBO、DPR、阴影、反射与后期质量。

## 验证

TypeScript 编译和 Vite 生产构建通过。桌面浏览器检查默认构图、旋转、鼠标水波和复位。高档采用 1024 折射缓冲、4× MSAA 后期与 16 样本 SSAO，性能不足时自动降级。60fps 是目标，尚未完成长时间性能基准。
